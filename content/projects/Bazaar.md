Bazaar App is a large-scale, UAE-based multi-category e-commerce marketplace serving thousands of daily shoppers. It features a scalable product architecture with dynamic variants and inventory management, advanced discount logic, and personalized product recommendations. The application supports deep linking for seamless navigation, WebSocket-based real-time order updates, and secure Stripe checkout integration. Advanced caching and performance profiling helped improve application loading time by 35%.
